## 2. Setup Database (Schema Push & Data Pull)
Agar database InsForge di cloud tersebut dapat digunakan dengan struktur aplikasi terbaru, jalankan perintah ini di dalam *workspace* ini:

**A. Menerapkan Struktur / Skema (*Push*):**
Menyelaraskan tabel-tabel di database cloud dengan kode lokal Anda.
```bash
npm run db:push
```

**B. Mentransfer Data ke Cloud (*Pull / Transfer*):**
Karena Anda menggunakan database cloud, jika Anda ingin "menarik" data lokal Anda saat ini untuk diisi langsung ke dalam database cloud production, Anda bisa menggunakan _script_ bawaan yang tersedia.
1. Sesuaikan variabel di dalam file `scripts/transfer-data.ts`.
2. Jalankan perintah:
```bash
npx tsx scripts/transfer-data.ts
```

*(Opsional) Jika Anda hanya ingin database cloud-nya bersih tapi terisi data awalan dummy yang otomatis (bukan data riwayat Anda), jalankan seed:*
```bash
npm run db:seed
```

## 3. Build & Run
Apabila Anda men-deploy ke Node.js VPS biasa, berikut perintah untuk merilis:
```bash
npm install
npm run build
npm run start
```
*(Untuk Vercel, cukup hubungkan repositori Github, build akan berjalan otomatis)*
